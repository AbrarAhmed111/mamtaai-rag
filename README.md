Designed to be your go-to starting point for any AI/LLM product: chatbots, agents, RAG backends, data extractors, and generative APIs.

## ✨ Features

- ⚡ **Powered by `uv`**: Instant virtual environment setup and lightning-fast dependency management (no slow `pip` installs).
- 🔄 **Universal LLM Client**: Pre-configured with OpenAI's API format. Switch seamlessly between **OpenAI**, **Groq**, **DeepSeek**, **Ollama (local)**, **OpenRouter**, **Together AI**, or **vLLM** just by tweaking `.env`.
- 💬 **Standard & Streaming Chat**:
  - `POST /api/chat` for standard JSON completions.
  - `POST /api/chat/stream` for real-time **Server-Sent Events (SSE)** token streaming.
  - `POST /api/chat/prompt` for single-turn quick queries.
- 📋 **Structured Outputs**: `POST /api/structured/entities` extracts guaranteed schema-validated Pydantic models from raw text.
- 🔍 **Vector Embeddings**: `POST /api/embeddings` for semantic search and RAG retrieval pipelines.
- 🛡️ **Type-Safe Settings**: Environment variables managed cleanly using `pydantic-settings`.
- 🧪 **Unit Tests Included**: Async unit tests with `pytest` and mock support.
- 📚 **Self-Documenting**: Interactive OpenAPI Swagger documentation at `/docs` and ReDoc at `/redoc`.

## ⚡ Quickstart

### 1. Prerequisites
Ensure you have [uv](https://docs.astral.sh/uv/) installed. If not:
```bash
# macOS/Linux:
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell):
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 2. Setup Environment
Clone the template, copy `.env.example` to `.env`, and install dependencies:
```bash
# Clone or enter your project folder
cd llm-fastapi-template

# Copy environment file
cp .env.example .env

# Install all dependencies with uv (creates .venv automatically)
uv sync
```

### 3. Configure Your LLM Provider
Open `.env` and configure your credentials.

#### Option A: OpenAI (Default)
```env
LLM_API_KEY=sk-proj-...
LLM_DEFAULT_MODEL=gpt-4o-mini
```

#### Option B: Groq (Ultra-Fast Inference)
```env
LLM_API_KEY=gsk_...
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_DEFAULT_MODEL=llama-3.3-70b-versatile
```

#### Option C: DeepSeek
```env
LLM_API_KEY=sk-...
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_DEFAULT_MODEL=deepseek-chat
```

#### Option D: Ollama (Free & Local)
```env
LLM_API_KEY=ollama
LLM_BASE_URL=http://localhost:11434/v1
LLM_DEFAULT_MODEL=llama3.2
```

#### Option E: OpenRouter (Access to 200+ Models)
```env
LLM_API_KEY=sk-or-v1-...
LLM_BASE_URL=https://openrouter.ai/api/v1
LLM_DEFAULT_MODEL=anthropic/claude-3.5-sonnet
```

## 🏃 Running the Server

Run with `uv`:
```bash
uv run uvicorn api.main:app --reload
```
Or use the runner script:
```bash
uv run python start_api_server.py
```

- **API Root**: [http://localhost:8000/](http://localhost:8000/)
- **Swagger Docs**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc**: [http://localhost:8000/redoc](http://localhost:8000/redoc)
- **Health Check**: [http://localhost:8000/health](http://localhost:8000/health)

## 📡 API Usage & Curl Examples

### 1. Chat Completion (`POST /api/chat`)
```bash
curl -X POST http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "Explain vector embeddings in one sentence."}
    ],
    "temperature": 0.7
  }'
```

### 2. Streaming Chat (`POST /api/chat/stream`)
Receives Server-Sent Events (SSE) token by token:
```bash
curl -N -X POST http://localhost:8000/api/chat/stream \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "Write a haiku about Python."}
    ]
  }'
```

### 3. Quick Single-Turn Prompt (`POST /api/chat/prompt`)
```bash
curl -X POST http://localhost:8000/api/chat/prompt \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "What are the 3 primary colors?"
  }'
```

### 4. Structured Extraction (`POST /api/structured/entities`)
Extracts entities, sentiment, and summary in validated JSON:
```bash
curl -X POST http://localhost:8000/api/structured/entities \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Satya Nadella announced Microsoft is investing $3 billion in cloud infrastructure in Germany to accelerate AI adoption."
  }'
```

### 5. Vector Embeddings (`POST /api/embeddings`)
```bash
curl -X POST http://localhost:8000/api/embeddings \
  -H "Content-Type: application/json" \
  -d '{
    "input": ["Artificial Intelligence", "FastAPI backend template"]
  }'
```

## 🛠️ Adding New Features to Your Product

When building a new AI product on top of this template:
1. **Add new schemas** in `schemas/` (e.g. `schemas/agent.py` or `schemas/rag.py`).
2. **Add pure logic & prompt templates** in `services/` (e.g. `services/rag.py` or `services/prompts.py`).
3. **Add route handlers** in `api/routers/` (e.g. `api/routers/rag.py`).
4. **Mount router** in `api/main.py` using `app.include_router(...)`.
